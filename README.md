# Sales Data Visualization and Analysis

## Project Overview

This project focuses on transforming raw sales data into meaningful visualizations using Python.

The analysis helps identify sales patterns, top-performing categories, regions, products, and profit trends.

## Objectives

- Analyze sales data
- Compare sales across product categories
- Compare sales across regions
- Identify top-selling products
- Analyze profit by category
- Study monthly sales trends
- Examine the relationship between sales and profit
- Present insights using visualizations

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations Created

1. Sales by Product Category
2. Sales by Region
3. Monthly Sales Trend
4. Top 10 Products by Sales
5. Profit by Product Category
6. Sales vs Profit

## Key Insights

The visualizations help identify the best-performing categories, regions, and products.

The monthly sales chart shows how sales change over time.

The profit analysis helps identify which categories contribute most to overall profit.

The Sales vs Profit chart helps understand the relationship between sales and profit.

## Project Files

- `Data_Visualization.ipynb` — Complete analysis and visualizations
- `Sample - Superstore.csv` — Dataset used for the project
- `README.md` — Project documentation

## Conclusion

This project demonstrates how raw sales data can be transformed into clear and useful visualizations using Python.

The visualizations make it easier to identify patterns, compare performance, and support data-driven decision-making.
